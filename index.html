QUOTA GUARDIAN & AUTO-PAUSE

NetGuardian

Protect your connection from severe ISP throttling. Monitors daily limits, audits per-app Wi-Fi consumption, and automatically pauses background downloads before the slow zone hits.

  • Custom Quotas: Set customizable daily caps (e.g. 28 GB) and FUP warning points (e.g. 20 GB).
  • Kernel-Level Auto-Pause: Freezes Steam, Epic Games, Riot Client, and Torrents safely in memory with 0 lost progress.
  • Per-App Wi-Fi Audit: Live table showing every background process and exact megabytes consumed today.
  • Zero-Flicker Live Dashboard: In-place smooth numeric updates with midnight auto-rollover.

CHANNEL BONDING & FAILOVER

NetFusion Studio

Merge multiple Wi-Fi signals (e.g. built-in Wi-Fi + phone USB tethering or USB Wi-Fi) into one combined network with dual operational modes.

  • ⚡ Boost Mode: Combines available Wi-Fi streams to maximize throughput and deliver seamless failover.
  • 🎛️ Control Mode: Steers bulk downloads to Wi-Fi 1 while dedicating low-latency Wi-Fi 2 exclusively to Discord, Zoom, and Games.
  • TCP_NODELAY Real-Time Engine: Eliminates packet buffering delay for zero-latency interactive voice and gaming.
  • 1-Click System Proxy: Instant WinINet broadcast routing without restarting your web browser.

Cross-Platform Compatibility & Quick Start

Run natively on your favorite operating system with minimal requirements.

🪟 Windows 10 / 11

  1. Download and extract NetGuardian_Suite_v1.0.zip.
  2. Double-click INSTALL_DESKTOP_SHORTCUT.bat.
  3. Launch NetGuardian or NetFusion directly from your Desktop icons!
INSTALL_DESKTOP_SHORTCUT.bat

🍎 macOS (Apple Silicon / Intel)

  1. Extract the ZIP and open Terminal in the folder.
  2. Install dependencies (Python 3.8+):
pip3 install psutil customtkinter
  1. Launch NetGuardian or NetFusion:
python3 net_guardian_app.py

🐧 Linux (Ubuntu, Debian, Fedora, Arch)

  1. Ensure python3 and tkinter are installed:
sudo apt install python3-tk python3-pip
  1. Install Python libraries:
pip install psutil customtkinter
  1. Launch:
python3 net_fusion_app.py
