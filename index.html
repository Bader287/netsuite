📡 PER-WI-FI FUP & QUOTA TRACKER

Individual Network Card Auditing

See exactly how much bandwidth you spend on each individual Wi-Fi adapter or mobile hotspot, with independent FUP threshold alerts.

  • Per-Adapter Progress Bars: Dual gauges for Daily Cap (e.g. 28 GB) and FUP warning zone (e.g. 20 GB) for each card.
  • Live Multi-Link Speeds: Independent real-time upload/download metrics and ping watchdog per connection.
  • Kernel-Level Auto-Pause: Freezes Steam, Epic Games, Riot, and Torrents automatically when any Wi-Fi nears its FUP limit.
  • Midnight Auto-Reset: Smooth daily rollover at midnight with atomic zero-loss state saving.
🚀 MULTI-WI-FI BONDING & STEERING

Socket Bonding & Automatic Failover

Combine your primary Wi-Fi with phone USB tethering or a USB Wi-Fi dongle for maximum speed and rock-solid connection reliability.

  • ⚡ Boost Mode: Round-robin channel bonding across all active adapters to maximize throughput with zero drops.
  • 🎛️ Control Mode: Steer bulk downloads to Wi-Fi 1, while dedicating low-latency Wi-Fi 2 exclusively to Discord, Zoom, and Games.
  • TCP_NODELAY Real-Time Engine: Zero-latency interactive voice, video calls, and responsive gaming.
  • 1-Click System Proxy: Instant OS-level WinINet broadcast routing without restarting your web browser.

Cross-Platform Compatibility & Quick Start

Run natively on your favorite operating system with minimal requirements.

🪟 Windows 10 / 11 (Standalone)

  1. Download NetFusionMax_Windows_v2.0.zip.
  2. Extract and double-click NetFusionMax.exe.
  3. Runs immediately — no Python or installation required!
NetFusionMax.exe

🍎 macOS (Apple Silicon / Intel)

  1. Extract the cross-platform package.
  2. Install dependencies (Python 3.8+):
pip3 install psutil customtkinter
  1. Launch NetFusion Max:
python3 netfusion_max_app.py

🐧 Linux (Ubuntu, Debian, Fedora, Arch)

  1. Ensure python3 and tkinter are installed:
sudo apt install python3-tk python3-pip
  1. Install Python libraries:
pip install psutil customtkinter
  1. Launch:
python3 netfusion_max_app.py
